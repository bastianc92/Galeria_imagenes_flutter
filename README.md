# 📸 Galería de Imágenes — Flutter + Firebase

Aplicación móvil desarrollada en Flutter que permite visualizar, recortar, 
compartir y almacenar imágenes en la nube usando Firebase Storage.

## ✨ Funcionalidades

- 🖼️ Visualización de imágenes locales y en la nube
- ✂️ Recorte de imágenes con `image_cropper`
- 📤 Compartir imágenes con `share_plus`
- 🔍 Zoom y vista completa con `photo_view`
- ☁️ Subida y descarga desde Firebase Storage

## 🛠️ Tecnologías utilizadas

- Flutter 3.x / Dart
- Firebase Storage
- image_cropper
- share_plus
- photo_view

## ⚙️ Requisitos

- Flutter 3.x
- Android SDK
- Firebase configurado con `google-services.json`

## 🚀 Instalación

1. Clona el repositorio:
   git clone https://github.com/bastianc92/Galeria_imagenes_flutter.git
2. Abre el proyecto en VS Code o Android Studio
3. Instala dependencias:
   flutter pub get
4. Ejecuta:
   flutter run
